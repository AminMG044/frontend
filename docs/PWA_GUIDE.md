# Progressive Web App (PWA) Guide

This guide covers the PWA implementation for the Dorisio frontend, including setup, testing, and deployment.

## Overview

The Dorisio frontend is now a Progressive Web App (PWA), providing:

- **Offline Support**: Works without internet connection
- **Installable**: Can be installed on desktop and mobile devices
- **App-like Experience**: Native app feel with home screen icons
- **Improved Performance**: Service worker caching for faster loads
- **Push Notifications**: Future capability for engagement

## Architecture

### Components

1. **Manifest.json** (`public/manifest.json`)
   - App metadata and configuration
   - Icons, colors, display modes
   - App shortcuts

2. **Service Worker** (Auto-generated by next-pwa)
   - Caching strategies
   - Offline support
   - Background sync

3. **Install Prompt** (`src/components/shared/pwa-install-prompt.tsx`)
   - Custom install UI
   - User-friendly installation flow
   - Dismissal tracking

4. **Next.js Configuration** (`next.config.js`)
   - PWA plugin integration
   - Caching strategies
   - Build optimization

## Setup and Installation

### Prerequisites

The PWA dependencies are already installed:
- `next-pwa` - PWA plugin for Next.js

### Icon Configuration

The PWA requires app icons at specific sizes:

**Required Icons:**
- `public/icon-192x192.png` (192x192 pixels)
- `public/icon-512x512.png` (512x512 pixels)

**Creating Icons:**

For development, placeholder icons are provided. For production:

1. **Using Online Tools:**
   ```bash
   # Visit https://convertio.co/svg-png/
   # Upload your SVG logo
   # Convert to PNG at required sizes
   # Save as icon-192x192.png and icon-512x512.png
   ```

2. **Using ImageMagick:**
   ```bash
   convert dorisio-logo.svg -resize 192x192 public/icon-192x192.png
   convert dorisio-logo.svg -resize 512x512 public/icon-512x512.png
   ```

3. **Using Photoshop/GIMP:**
   - Open your logo
   - Resize to 192x192 and 512x512
   - Export as PNG
   - Save with required filenames

**Icon Requirements:**
- Format: PNG
- Sizes: 192x192 and 512x512 pixels
- Design: Recognizable at small sizes
- Background: Transparent or solid color

### Manifest Configuration

The manifest is configured in `public/manifest.json`:

```json
{
  "name": "Dorisio - Support Your Favorite Creators",
  "short_name": "Dorisio",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#ffffff",
  "theme_color": "#6366f1",
  "icons": [...]
}
```

**Key Settings:**
- `display: "standalone"` - Full-screen app experience
- `theme_color` - Matches brand color
- `start_url: "/"` - App entry point

## Caching Strategy

The PWA uses Workbox for intelligent caching:

### Cache Strategies

1. **Static Assets** (Images, Fonts, CSS)
   - Strategy: Cache First
   - Max Age: 1 year
   - Update on build

2. **JavaScript Bundles**
   - Strategy: Stale While Revalidate
   - Serve cached, update in background
   - Fast initial load

3. **API Responses**
   - Strategy: Network First
   - Try network, fallback to cache
   - Offline support

4. **HTML Pages**
   - Strategy: Network First
   - Always try fresh content
   - Cache for offline fallback

### Cache Sizes

- Runtime Cache: 50 MB
- Precache: 10 MB
- Total: 60 MB

## Installation Flow

### Desktop Installation

1. User visits the site
2. Browser detects PWA criteria
3. Install prompt appears in address bar
4. Custom install UI shows in bottom-right
5. User clicks "Install"
6. App is added to desktop/applications

### Mobile Installation

1. User visits the site on mobile
2. Browser detects PWA criteria
3. Install prompt appears
4. User adds to home screen
5. App launches in standalone mode

### Install Criteria

Browsers show install prompt when:
- Site is served over HTTPS
- Service worker is registered
- Manifest is valid
- Site has been visited twice
- User has interacted with the site

## Troubleshooting

### Install Prompt Not Showing

**Problem:** Install prompt doesn't appear.

**Solutions:**
1. Verify HTTPS is enabled
2. Check service worker is registered
3. Validate manifest.json
4. Visit site at least twice
5. Interact with the site
6. Check browser console for errors

### Service Worker Not Registering

**Problem:** Service worker fails to register.

**Solutions:**
1. Check next.config.js configuration
2. Verify build includes PWA
3. Check browser console for errors
4. Clear cache and rebuild
5. Verify manifest path is correct

### Offline Mode Not Working

**Problem:** App doesn't work offline.

**Solutions:**
1. Verify service worker is active
2. Check cache contents in DevTools
3. Verify caching strategy
4. Test critical assets are cached
5. Check network tab for failed requests

### Icons Not Displaying

**Problem:** Icons don't appear or are broken.

**Solutions:**
1. Verify icon files exist in public/
2. Check icon file sizes match manifest
3. Verify icon format is PNG
4. Clear browser cache
5. Rebuild the app

### Update Issues

**Problem:** App doesn't update to new version.

**Solutions:**
1. Service worker updates automatically
2. Users need to close and reopen app
3. Use `skipWaiting: true` for immediate updates
4. Check service worker version in DevTools
